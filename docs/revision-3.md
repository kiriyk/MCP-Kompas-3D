# Редакции 3–4: нативный PDF, перенос и плотные склады

Проверено прямыми вызовами на КОМПАС-3D v21, затем через stdio MCP.

## Что в актуальном плане

`examples/build_factory_v4_direct.py` — актуальная редакция. А0 горизонтальный, 40 × 24 м, вид 1:50. Длинный охлаждающий тоннель **сохранён**: 12500 × 780 мм, H=1530 мм. Предыдущая редакция 3 убрала его вследствие неверного понимания запроса; она оставлена только как история.

Широкий центральный транспортный коридор устранён. Производственные помещения расширены вниз на 4 м; между складами и производством оставлен проход персонала 1500 мм. Электрокары пересекают его поперёк через встречные ворота, а не ездят вдоль прохода. Основные складские проезды — 4000 мм. Поперечные зоны погрузки между рядами — 3150 мм. Подбор конкретного электрокара и проверка его траектории поворота не выполнялись.

На складах сырья, продукции и упаковки показаны стеллажные ряды, стойки, балки и паллеты с настилом и девятью опорными блоками. Отображённые паллетные места: сырьё 15, продукция 18, упаковка 12; на плане предусмотрены два уровня для основных складов. Паллеты 1200 × 800 мм, повёрнутые паллеты 800 × 1200 мм. Геометрическая проверка исключает пересечения складского оборудования с основными и поперечными проездами.

## Проверенные особенности API

- PDF экспортирует сам КОМПАС: `IApplication.Converter(Bin/Pdf2d.dll)`, параметры `IPdf2dParam` из установленного Pdf2d.tlb, команда 0, `Convert(..., 0, false) → 1`. Converter.GetFilter здесь дал пустую строку — это не препятствует проверенной команде 0.
- `UserFormat=false`, Scale=1: формат исходного листа. `UserFormat=true`, WidthUserSheet/HeightUserSheet и Scale=min(новая ширина/исходная, новая высота/исходная): весь лист на другой бумаге. CDW не меняется. ColorType=2 — цвета слоёв, 1 — ч/б. Параметры после вызова восстанавливаются.
- Проверены четыре варианта А1→А1/А4, цвет/ч/б. Размеры страниц подтверждены по MediaBox, отсутствие цвета в ч/б — по растровому изображению PDF. Для плана выгружаются аналогичные А0/А4.
- Сохранение CDW — через API7 SaveAs с проверкой свежего уникального файла и итогового пути. PDF требует сохранённый неизменённый документ и один лист.
- PDF-конвертер v21 пишет некорректные ToUnicode CMap для части встроенных GOST-шрифтов оформления/размеров: Poppler предупреждает об invalid bfrange, pypdf может не извлечь текст. Визуальное отображение проверяется отдельным рендером. Эта особенность native export не исправляется внешним PDF-генератором.
- У текстового объекта применяется Arial через ITextFont. После TextItem.Update необходим IDrawingObject.Update. Иначе читаемое FontName уже новое, но изображение всё ещё старое. Проверены — → × Ø и кириллица; GOST type A искажает некоторые из этих символов.
- Arc Direction=false означает против часовой стрелки. 0→90 — четверть окружности, True давал 270°. Геометрия дверей учитывает вертикальные и горизонтальные стены.
- Перенос: SelectionManager.SelectedObjects либо session references → ksNewGroup(1), ksAddObjGroup, ksEndGroup → ksCopyGroupToDocument(group, sourceDocument.reference) → ksMoveObj при смещении → ksStoreTmpGroup. Без StoreTmpGroup копия остаётся временной и не попадает в геометрию вида.
- Проверен перенос выбранных rectangle+circle из вида 1:10 в вид 1:50 со смещением (200,300) мм. Реальные размеры и координаты сохранены; source objects остаются. System clipboard не используется. Unsupported types отклоняются до операции.
- Ошибка до вставки очищает target temporary group; после вставки при неопределённом результате выдаются оставшиеся references для проверки. Независимый review выявил отсутствующий общий cleanup; regression test воспроизвёл его, после исправления проходит.

## Запуск

```powershell
$env:KOMPAS_EXECUTABLE='C:\path\to\KOMPAS-3D v21\Bin\KOMPAS.exe'
.venv\Scripts\python.exe examples/probe_io_direct.py
.venv\Scripts\python.exe examples/probe_io_mcp.py
.venv\Scripts\python.exe examples/build_factory_v4_direct.py
```

Объекты чертятся прямыми вызовами Adapter, без MCP. Отдельные probe проверяют уже добавленный MCP. Артефакты и машинные журналы остаются в artifacts/, исключённом из Git. Workflow skill будет обновляться отдельным последующим шагом.
