# Local KOMPAS v21 MCP

Учебный проект: минимальный локальный stdio MCP для Windows/КОМПАС-3D v21. Пользователь поручил самостоятельно выбирать решения и планировку. Пример — здание 40×24 м на А0 горизонтальном, масштаб 1:50, два производственных участка, кухня, раздевалка, склады, пешеходные проходы и проезды электрокаров. Это демонстрационный эскиз, параметры проходов задаются в примере, а не заявляются нормативными.

Python 3.12, официальный MCP SDK 1.30.0 (стабильная ветка v1), pywin32. Сервер, последовательный STA worker и CAD adapter — три небольших модуля. SDK COM загружается из установленного КОМПАСа, не включается в Git. stdout только для MCP; журнал в stderr. Конфигурация через переменные среды, без машины пользователя в коде.

Инструменты: подключение/состояние, документы и сохранение, лист, виды, слои, линии/прямоугольники/окружности/дуги/текст, штриховка, линейные размеры, копирование/перенос/поворот/удаление, чтение объектов и преобразование координат, экспорт PNG. Каждая операция добавляется после интеграционного теста на отдельном документе. Недоступные функции фиксируются, не выдаются за рабочие.

Все COM-вызовы выполняются последовательно в одном STA-потоке. Ссылки имеют session id и document id. В аргументах явный document_id; чужой активный чертёж не используется случайно. Пути нормализуются. Постусловия важнее неоднозначного bool метода. Ошибки инструментов возвращаются как MCP tool errors. При тайм-ауте worker остаётся занятым, повтор операции автоматически не выполняется.

Проверки: unit-тесты нормализации пути, преобразования координат с поворотом, проверки ссылок и последовательного исполнения; настоящий stdio клиент проверяет initialize/tools/list/tools/call, отрицательные аргументы, неверные ссылки, создание отдельного чертежа, сохранение и чтение после открытия. Готовый план построен этим же клиентом. Репозиторий локальный, публикация на GitHub — отдельный будущий шаг.
