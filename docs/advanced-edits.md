# Три дополнительные операции v0.5

Все сначала проверены напрямую через SDK, затем через MCP stdio. Документы проекта не менялись: probes создают отдельные тестовые чертежи.

## set_object_properties

`document_id`, `reference`, необязательные `angle` и `style`; хотя бы один обязателен.

- `angle` — абсолютный угол **прямоугольника** относительно осей его вида, нормализуется в [0,360). Начало, размеры, слой и reference сохраняются. Для вращения других объектов вокруг выбранной точки служит прежний `rotate_object`.
- `style` — стандартный стиль линии 1–9 у прямоугольника, отрезка, окружности, дуги или полилинии. Проверены стили 1, 2, 4 и сохранение после повторного открытия. Пользовательские стили пока не включены.
- Тексты, штриховки, размеры, Bezier и составные контуры исключены. Общий setter Style составного контура на этой установке не обеспечил изменение сегментов; метод отклоняет этот тип до мутации.
- При ошибке Update/постусловия исходные свойства восстанавливаются; при неудаче восстановления выдаётся явная ошибка и требуется проверить состояние перед повтором.

## edit_linear_dimension

`document_id`, `reference`, точки `x1,y1,x2,y2,x3,y3`; `orientation` — horizontal/vertical/parallel или null для сохранения текущего направления.

Меняет существующий нативный линейный размер, включая измеряемые точки и отступ. **Геометрию помещения/машины не меняет.** Координаты в миллиметрах вида. Возвращает фактические точки, направление и nominal_value. При горизонтальном размере проверяется Y3, при вертикальном X3, при параллельном — подписанное перпендикулярное расстояние от X3/Y3 до линии между измеряемыми точками. КОМПАС может перемещать текст вдоль размерной линии; это допустимо. Игнорирование отступа отклоняется с rollback. Нулевой измеряемый интервал отклоняется до присваиваний.

## get_object_boundaries

`document_id`, `reference` нативного контура или штриховки. Только чтение.

Возвращает `boundaries`: для каждой границы closed и массив segments; для линии — концы, для круговой дуги — центр, радиус, углы, clockwise. `bounds` содержит left/bottom/right/top/width/height по объединению всех границ. Координаты относятся к владельцу-виду; толщина линий не включается. Для дуг учитываются только пройденные экстремумы, а не полный круг.

Чтение поддерживает IContourLineSegment/IContourArc через точный QueryInterface. Другие кривые, пустые границы, дуги с совпадающими начальным/конечным углами (неоднозначность полного круга) и более 10000 сегментов отклоняются. Метод не переносит геометрию и не создаёт кэш references между сессиями.

## Проверки

28 unit tests: валидация до COM, сохранение идентичности, границы дуг, отказ игнорируемому отступу parallel и восстановление исходных значений, прежние проверки MCP/IO/текстов.

`examples/probe_advanced_edits_direct.py`: абсолютный угол и стили пяти типов примитивов, горизонтальный 6000, вертикальный 2600 и наклонный 5000 мм, границы дуги 90° и прямоугольной штриховки; Save/Close/Open и PNG.

`examples/probe_advanced_edits_mcp.py`: список 41 инструмента, три новых метода, отказы неподдерживаемому типу/стилю/нулевому размеру без изменения измерения, Save/Close/Open и PNG. JSON результатов сохраняется в artifacts/.

```powershell
$env:KOMPAS_EXECUTABLE='C:\path\to\KOMPAS-3D v21\Bin\KOMPAS.exe'
.venv\Scripts\python.exe -m unittest discover -s tests
.venv\Scripts\python.exe examples/probe_advanced_edits_direct.py
.venv\Scripts\python.exe examples/probe_advanced_edits_mcp.py
```
