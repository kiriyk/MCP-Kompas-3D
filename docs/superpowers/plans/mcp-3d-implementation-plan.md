# KOMPAS MCP 3D Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Реализовать переиспользуемую цепочку MCP «детали → сборка → связанные чертежи» и проверить её учебной башней для кубиков.

**Architecture:** Сохранить FastMCP и единственный STA worker. Добавить отдельные mixin-модули для 3D-документов, эскизов/операций, сборок и связанных видов. Рецепт башни использует публичные команды, геометрия башни не входит в адаптер.

**Tech Stack:** Windows, установленный КОМПАС-3D v21 SDK, Python существующего `.venv`, pywin32, FastMCP, unittest.

**Spec:** `C:/Users/user/Documents/Codex/2026-10-11/new-chat-2/outputs/mcp-3d-dice-tower-design.md`.

## Global Constraints

- Все COM-вызовы выполняются последовательно на STA worker; прямой SDK-probe и MCP не работают одновременно.
- Поддержать существующие 41 команду 2D без изменения их контрактов.
- Явные document_id, типизированные ссылки с принадлежностью документу и сессии; никаких публичных execute_python.
- Геометрия в мм; углы в градусах. Системы координат и направления выдавливания фиксируются по фактическому SDK-probe.
- Тайм-аут означает неизвестный исход; автоматический повтор мутации запрещён.
- Проверка фактического состояния, свежих файлов и Save/Close/Open обязательна; COM bool сам по себе не доказывает успех.
- Пользовательские артефакты — `outputs` чата. Промежуточные артефакты — `work`; воспроизводимые probes и примеры — в репозитории.

## Review Focus

1. Чужие и устаревшие ссылки отклоняются до COM; покрыть в задачах 1–2.
2. Незамкнутые, самопересекающиеся и вырожденные профили отклоняются; покрыть в задаче 2.
3. Исключение при редактировании эскиза не оставляет бесконтрольно открытый режим; покрыть в задаче 2.
4. Переоткрытая сборка сохраняет ссылки на детали и положения компонентов; проверить в задаче 3.
5. Изменение модели обновляет геометрию связанного вида и разреза; проверить в задаче 4.

## Этап B: Сборки и экспорт

### Task 3: Компоненты, положение и STL

**Files:** создать `src/kompas_local_mcp/model_assembly.py`, `src/kompas_local_mcp/model_io.py`, `tests/test_model_assembly.py`, `tests/test_model_io.py`, `examples/probe_model_assembly_direct.py`, `examples/probe_model_assembly_mcp.py`; изменить PUBLIC_TOOLS.

**Interfaces:**
- `insert_component(document_id: str, path: str, name: str = "Component") -> dict`, возвращает component_reference.
- `set_component_placement(document_id: str, component_reference: str, origin: list[float], x_axis: list[float], y_axis: list[float]) -> dict`; ортонормальные оси, правая система, z = x × y. Возвращает фактическое положение.
