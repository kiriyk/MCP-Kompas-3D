# Правки по описанию и проверка результата

## Поиск и состав предмета

Сначала document_state, активный вид и list_objects(owner). Найди подпись, соседние контуры, слой и габариты. Проверь truncated; увеличь limit до 10000, не выбирай из неполного списка. Поддержаны line, rectangle, circle, arc, text, hatch, polyline, contour, bezier, linear_dimension. Для контура/штриховки нужны get_object_boundaries; у Bezier список содержит число узлов, не полную геометрию. При неоднозначности описания уточни объект, до этого выполняй независимую проверку.

Комната/станок/паллет/стул — не ассоциативная сборка. Собери references всех деталей, надписей, линий, штриховок и размеров. move_objects переносит временную группу одного вида; после операции детали остаются самостоятельными. По необходимости сначала переключи вид set_active_view; особенно для одиночных API5 move/copy/rotate/mirror/array. Слои помогают выбору, но номер слоя не универсальный смысл объекта.

Если части находятся в разных видах, move_objects всего набора не сработает. Разбей references по виду. Для единого перемещения на листе возьми вектор Δsheet = scale·R(angle)·Δowner исходного вида; для каждого вида Δowner = R(-angle)·Δsheet/scale. R — обычная матрица поворота градусов. Системный вид обычно scale=1, angle=0, но читай фактическое состояние. Не прибавляй положение начала вида к вектору. Проверь направление через view_to_sheet на двух точках до изменения; затем переноси каждую группу и сверяй согласованность на листе. Это несколько операций без общей транзакции: записывай успешные шаги и не повторяй весь набор после сбоя.

Изменение комнаты: resize_rectangle для прямоугольных стен/деталей, перенеси общую стену и проёмы, перерисуй изменившуюся штриховку, исправь подпись и нативные размеры. Сначала сформулируй итоговые координаты и зависимые объекты; проверь коллизии, проходы и дверные проёмы после правки. MCP не разбирает словесные описания: это работа агента.

## Углы, зеркала, массивы

rectangle имеет angle перед style; polyline имеет closed перед style. Необязательные аргументы — именованные. Для абсолютного исправления наклона прямоугольника используй set_object_properties(angle=0), если предмет должен быть вдоль осей; сложный символ исправляй согласованно, сохраняя правильную ориентацию к стене. rotate_object задаёт относительный поворот вокруг точки.

arc идёт против часовой стрелки (IArc.Direction=False): 0→90 — четверть, 90→0 — 270°. Для обратного обхода поменяй начало и конец. Четверти дверей: 0→90, 90→180, 180→270, 270→360; проверь конечные точки и створку.

mirror_object(copy=False) заменяет исходник и инвалидирует его токены. Зеркальный прямоугольник может иметь отрицательные Width/Height: проверяй углы и реальные вершины, абсолютных габаритов недостаточно. Массивы создают независимые копии; count включает исходник; circular_array при полном круге не дублирует последний угол и поворачивает ориентацию детали. Для составного символа повторяй весь набор согласованно, не только внешний прямоугольник.

## Текст и нативные размеры

При создании текста используй Arial (default), явно проверяй кириллицу, `—`, `×`, `Ø` на PNG и после сохранения. GOST type A давал квадраты/ошибочные символы. Не подменяй размеры текстом. edit_text поддерживает непустой однострочный текст с одним TextLine и TextItem; сложный текст не правится этим методом.

Внутри адаптера edit_text использует IText.Replace: IText.Str/ITextItem.Str сбрасывали сохраняемый шрифт, даже когда UI выглядел правильно. Не возвращай прежнюю реализацию без проверки Save/Close/Open.

linear_dimension создаёт настоящий размер КОМПАС. edit_linear_dimension требует все шесть координат; orientation=None сохраняет направление, либо horizontal/vertical/parallel. Он меняет размер, не геометрию, и не создаёт ассоциативности. Проверь концы, номинал и линию размера: horizontal — Y3, vertical — X3, parallel — знаковое перпендикулярное смещение; сдвиг текста вдоль параллельной линии допустим. Не обещай изменение длины стены через правку размера.

set_object_properties: absolute angle только rectangle; style 1..9 для rectangle/line/circle/arc/polyline. Реально проверены стили 1,2,4; не обещай все визуальные варианты без PNG. Для contour, hatch, text, Bezier, dimension этот setter не поддержан.

get_object_boundaries работает только contour/hatch; возвращает петли, замкнутость, отрезки/дуги и union bounds в мм вида без толщины штриха. Учитывает посещённые экстремумы дуг. Не поддерживает другие кривые, пустые границы, неоднозначную дугу полного круга с совпавшими углами и слишком большие границы (>10000 сегментов).

## Между документами

copy_objects_to_document: явные references либо selected=True, не оба. get_selected_objects читает поддержанные типы выделения; неподдержанный тип вызывает ошибку. Зарегистрируй оба документа в одной сессии и активируй нужный вид назначения перед копированием. dx/dy — мм вида назначения. Разные масштабы видов не масштабируют реальную геометрию. Источник сохраняется; системный clipboard не нужен. После копирования проверь вид, слои, текст, количество и координаты, затем сохрани целевой документ.

## Сохранение и экспорт

save_document использует свежий промежуточный CDW и SaveAs конечного пути, проверяет путь/размер/время файла; при ошибке может оставить recovery copy. Старый файл по тому же пути не доказывает сохранение. Проверь возвращённый saved и фактический файл. Для проверки стойкости свойств безопасно переоткрывай только собственный сохранённый документ; close_document не сохраняет. Нельзя закрывать чужой грязный документ.

export_pdf вызывает **нативный Bin/Pdf2d.dll КОМПАС**, не сторонний PDF-генератор. Требуется сохранённый неизменённый CDW и один лист. `paper="sheet"` сохраняет физический формат листа, масштаб 1; `paper="A4"` (или A0..A3) вписывает весь лист в выбранный формат. landscape задаёт ориентацию экспорта; color=True — цвета слоёв, False — ч/б. Формат CDW не меняется; параметры конвертера восстанавливаются. После любого изменения сначала снова save_document. Если запрошены обе версии, выгружай цветную и ч/б отдельно в уникальные пути.

export_png: dpi=100 default, color_mode="black" default или "layer" для цветов слоёв. Проверяй открытием PNG: читаемость, положение видов, рамку, подписи, масштабы, дуги, двери, мебель, пересечения. Для PDF проверяй число страниц, физические размеры и видимые элементы; pypdf/Poppler допустимы для проверки, не заменяют нативный экспорт. Не называй нормативно согласованным план, нарисованный для изучения API.
