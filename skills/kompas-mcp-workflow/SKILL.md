# КОМПАС-3D v21 через локальный stdio MCP

Инструкции для агента. Основной сервер — **kompas-local-mcp v0.5, 41 инструмент**, зарегистрированный в MCP-клиенте. Пути установки задаются в локальной конфигурации и не являются частью скилла. Сначала прочитай [локальный запуск](references/local-workflow.md). Схемы `tools/list` текущего сервера важнее снимка справочника.

## Основной порядок

1. Сам запусти КОМПАС перед подключением, если он не работает; используй известный v21, проверь путь. Подключённый MCP и доступный чертёж — разные состояния.
2. Используй инструменты зарегистрированного **kompas-local-mcp**. Сверь доступные методы с текущими схемами MCP. Если сервер отсутствует или не подключён, проверь регистрацию и сообщи о необходимости подключить его; не запускай отдельный stdio-клиент как обход и не подменяй сервер другим MCP. Настройку подключения меняй только в рамках запроса пользователя.
3. `connect` → `open_document(path)` либо `create_drawing` → получи `document_id`. Затем `document_state` и `list_objects(coordinate_space="owner")`. Внешне открытый пользователем чертёж не даёт идентификатор автоматически: зарегистрируй его по точному пути. Глобальных `get_active_document`/`list_open_documents` здесь нет.
4. Для нового плана установи лист через `set_sheet`; создай именованный вид через `create_view` и проверь его фактический масштаб в `document_state`. 1:50 — `scale=0.02`; старый обход через transform_object не нужен. У существующего вида нет публичного метода изменения масштаба: не выдавай повторное create_view за изменение старого.
5. Черти в реальных миллиметрах вида. Для правок по описанию найди предмет по подписи, типу, координатам, габаритам и слою; у составного предмета включи все детали. См. [редактирование и проверку](references/editing-and-verification.md).
6. Проверь фактические объекты, размеры, углы, слои и читаемость через PNG. `saved`/`updated`/`moved` и отсутствие MCP isError — часть проверки, а не замена геометрической и визуальной проверки.
7. `save_document` → при необходимости `export_pdf`; для существенных изменений проверь сохранённые свойства после безопасного Close/Open. `close_document` закрывает **без сохранения**: не закрывай чужие или грязные документы ради проверки.

## Инварианты

- `document_id` и строковый `reference` действуют только в текущем процессе сервера и своём документе. После перезапуска/Close/Open получи их заново. Числовой `api_reference` — диагностика, не аргумент reference. Перезапуск серверного процесса создаёт новую сессию.
- COM выполняется последовательно одним STA worker. Не запускай одновременно прямой API-скрипт, другой MCP-клиент или повтор зависшего изменения.
- Геометрия, переносы и габариты — мм **вида**; начало вида — мм **листа**; углы — градусы. Высота создаваемого текста и шаг штриховки — мм бумаги. Для сверки листа используй `view_to_sheet`/`list_objects(coordinate_space="sheet")`.
- Перед необязательными параметрами всегда используй **именованные аргументы**: `rectangle(..., style=2)`, `polyline(..., style=2)`. У rectangle angle стоит перед style; у polyline следующий после points — closed. Позиционные style уже вызвали наклоны 1–2° и замкнутые маршруты.
- Тайм-аут 60 секунд означает неизвестный исход. Отмена/закрытие клиента не отменяет COM. Не повторяй мутацию автоматически: дождись освобождения worker, прочитай состояние и продолжи с последнего подтверждённого шага. Подробнее — в локальном запуске.
- Схема помещения, технологические зависимости и состав сборного символа не ассоциативны: агент явно обновляет связанные стены, проёмы, подписи, штриховки и размеры.
